# The Living Past

An interactive historical exploration system. Enter history through a time,
place, person, event, or object — then follow the connections wherever they
lead.

> "I wonder what happened here, and what else is connected to it."

This is a long-term personal hobby/learning project. It is not a game and
does not simulate history. V1 is a factually grounded, source-aware
exploration tool; later versions may add AI guidance, alternate timelines,
and narrative/simulation layers — see `docs/BACKLOG.md`.
